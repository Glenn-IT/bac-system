========================================
BAC SYSTEM - QUICK SETUP GUIDE
========================================

📦 INSTALLATION STEPS:

1. START XAMPP
   - Open XAMPP Control Panel
   - Click "Start" on Apache
   - Click "Start" on MySQL
   - Wait for both to turn green

2. IMPORT DATABASE
   - Open browser: http://localhost/phpmyadmin
   - Click "New" to create database (or use Import)
   - Click "Import" tab
   - Choose file: database.sql
   - Click "Go" button
   - Wait for success message

3. FIX PASSWORDS (IMPORTANT!)
   - Open browser: http://localhost/bac-system/fix_passwords.php
   - Wait for "ALL PASSWORDS FIXED" message
   - This creates proper password hashes

4. ACCESS SYSTEM
   - Go to: http://localhost/bac-system/public/
   - Login with: admin / admin123
   - Should work now!

========================================
TROUBLESHOOTING:
========================================

❌ Cannot access system?
   → Check XAMPP is running
   → Use correct URL with /public/

❌ Database error?
   → Import database.sql again
   → Check MySQL is running

❌ Cannot upload files?
   → Check uploads/ folder exists
   → Check folder permissions
