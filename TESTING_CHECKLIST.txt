🐛 TROUBLESHOOTING
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Issue: Blank page / White screen
Fix: 
  1. Check Apache is running
  2. Check database.sql imported correctly
  3. Check config/db.php settings

Issue: Cannot upload files
Fix:
  1. Check uploads/ folder exists
  2. Right-click uploads/ → Properties → Security
  3. Give "Everyone" write permissions (Windows)

Issue: Login fails
Fix:
  1. Check database has users
  2. Use exact passwords: admin123, secret123, etc.
  3. Clear browser cache

Issue: Database connection error
Fix:
  1. Check MySQL is running in XAMPP
  2. Verify database name: bac_system
  3. Check config/db.php settings

Issue: Session errors
Fix:
  1. Restart Apache in XAMPP
  2. Clear browser cookies
  3. Close all browser tabs
