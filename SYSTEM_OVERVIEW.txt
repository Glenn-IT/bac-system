📊 AUTO STATUS LOGIC
--------------------------------
The system automatically calculates document status:

IF no file uploaded:
   → Status = MISSING

IF file exists:
   IF expiration_date is null:
      → Status = VALID
   
   IF expiration_date < today:
      → Status = EXPIRED
   
   IF expiration_date within 30 days:
      → Status = FOR RENEWAL
   
   IF expiration_date > 30 days from now:
      → Status = VALID

═══════════════════════════════════════════════════════════════

📈 COMPLIANCE CALCULATION
--------------------------------
Compliance % = (Valid Documents / Total Documents) × 100

Example:
- Total Documents: 13
- Valid: 10
- For Renewal: 2
- Expired: 1
- Missing: 0
→ Compliance = 10/13 = 76.9%

Color coding:
✓ Green bar: ≥80%
⚠ Yellow bar: 50-79%
✗ Red bar: <50%
