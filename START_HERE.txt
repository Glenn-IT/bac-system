⚡ INSTALLATION IN 3 STEPS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

STEP 1: Start XAMPP
   → Start Apache + MySQL

STEP 2: Import Database
   → phpMyAdmin → Import → database.sql

STEP 3: Fix Passwords (IMPORTANT!)
   → Go to: http://localhost/bac-system/fix_passwords.php
   → Wait for "ALL PASSWORDS FIXED!" message
   → This creates correct password hashes

STEP 4: Access System
   → http://localhost/bac-system/public/
   → Login: admin / admin123

DONE! ✓
